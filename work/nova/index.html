NOVA

What if network documentation could keep up?

01 /
Context

A network diagram can be accurate the day it’s drawn and misleading a week later. During my Imagineering internship, I built NOC Visibility & Automation (NOVA) to explore how engineers might spot that gap.

02 /
Approach

I split the problem into four jobs: discover hosts, map their relationships, organize reference material, and show what needs attention. Building each part separately let me test how information might move between them.

03 /
What I built

MPH Dashboard. A Flask and GridStack workspace for arranging alert, topology, and documentation-health views.

LLM Wiki. A prototype for turning source material into structured, cross-referenced documentation.

Network Diagram Tool. A React Flow canvas for arranging hosts and their connections.

DNS Recon Tool. A subnet-scanning component designed to supply host and status information.

04 /
What I learned

Connecting four tools made input validation as important as the interface. I corrected path handling and unsafe YAML processing, fixed a startup issue, and prepared a demonstration for the team.

Scope. NOVA was a self-directed, intern-only learning exercise. It never consumed live API data or ran as a production service.
